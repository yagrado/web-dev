Lego reviews

Boquet of Roses

Building this was so fun,it took about two to three days only because i took breaks,however it its possible to finish the set in one day.

Plum Blossom

Building the plum blossom set was also fun, me and my cousin got the same set and we just sat on the ground building our legos while talking and listening to music so it was not bad. Only bad thing was that my cat knocked it down from the place i had it sitting and i lost a couple of pieces.

Spider man vs. Ghost Rider motorcycle

This is not the exact lego set i was looking for, however its similar to one i built a while ago with my brother. This one was not bad to build it was pretty fun since i had my brother's company, i did not get any help which made the process slower but i did not mind since i love building legos.

Lighting McQueen

ive never built the Lighting McQueen lego set but i want to build it sometime because i love cars and also because i think it will be cool to have a Lighting McQueen lego set sitting on my vanity or somewhere.

Polaorid OneStep SX-70 Camera

The polaroid camera set seems very cute and it seems like something that will take maybe at least 3 days to put together which i think is a good thing since i get bored every once in a while i could just work on this set to consume time.
